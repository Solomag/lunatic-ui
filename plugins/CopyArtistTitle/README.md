# Copy Artist - Title

Adds **Copy Artist - Title** to the context menu of a track, a selection of tracks, an album or a playlist. It copies one `Artist - Title` line per track to the clipboard, for example:

```
The Architect - Les pensées
The Architect, Shaolin Beatmaker - Old Mob Blues
```

- Several artists are joined with `, `.
- The version is added the way TIDAL shows it: `Title (Remix)`.
- Names come straight from TIDAL, so even a long playlist is copied at once.

Requested in [Inrixia/luna-plugins#146](https://github.com/Inrixia/luna-plugins/issues/146).
