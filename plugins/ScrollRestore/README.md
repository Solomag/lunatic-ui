# Scroll Restore

TIDAL starts a page at the top when you open it again from the sidebar, the *Tracks / Albums* tabs or a link, so in a long playlist or your collection you have to scroll all the way back. Scroll Restore remembers how far you scrolled on each page and puts you back there.

- Works for collection tabs, playlists, albums, artists, search results and the home page.
- If the list has not loaded that far yet, it keeps loading more items until the position is reached.
- Scrolling yourself while it restores stops it, so it never fights you.
- Only positions you scrolled to are remembered, for the last 200 pages, until TIDAL is closed.

Requested in [Inrixia/luna-plugins#122](https://github.com/Inrixia/luna-plugins/issues/122).
